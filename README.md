# 🔁 Duplicate Complaint Management

Multiple citizens may report the same public issue.

Instead of treating every complaint separately, **Samadhan Path** can group related complaints under a common **Master Issue**.

### Key Benefits

| Benefit | Impact |
|---|---|
| **Reduced Duplicate Work** | Departments avoid resolving the same issue repeatedly |
| **Better Prioritization** | Frequently reported issues receive greater visibility |
| **Citizen Impact Analysis** | Authorities can identify how many people are affected |
| **Improved Resource Allocation** | Workers and resources can be deployed more efficiently |
| **Better Analytics** | Recurring public problems become easier to identify |

# ✅ Resolution Verification

A complaint should not be marked as resolved without appropriate evidence.

### Resolution Process

1. Worker completes the assigned task
2. Worker uploads proof of completed work
3. Submitted proof is reviewed
4. AI or an authorized authority assists in verification
5. Complaint status is updated
6. Citizen receives resolution information

> This process improves **transparency, accountability, and trust** in grievance resolution.
